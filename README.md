## ⚡ Quick Start

No installation or node setup required!
1. Download or clone this folder.
2. Double-click **`index.html`** to launch the store in any browser.

## 🌟 Key Highlights

- **⚡ Zero Setup**: Pure client-side code running directly in Google Chrome, Edge, Safari, and Firefox.
- **🇮🇳 India E-Commerce Ready**: Native INR (`₹`), UPI payments (GPay/PhonePe), BlueDart shipment tracking, and GST tax invoice generation.
- **🌐 Global Flexibility**: Multi-currency switcher (`₹ INR`, `$ USD`, `€ EUR`, `AED`) & Bilingual toggle (`EN` / `हिन्दी`).
- **🌓 Light & Dark Theme**: Default crisp light mode with high-contrast OLED dark mode.
- **👑 VIP Loyalty Club**: Tiered rewards program (Bronze &rarr; Silver &rarr; Gold &rarr; Platinum) with cashback and perks.

## 🎯 Top Features

### 🛒 Shopping & Discovery
- **Predictive Search (`Ctrl+K`)**: Live autocomplete thumbnail results and popular search tags.
- **Storewide Wishlist**: Clickable `♡`/`♥` heart buttons synced across cards and your Account.
- **Hover Zoom & Lightbox**: Interactive cursor lens zoom and distraction-free fullscreen gallery.
- **Side-by-Side Comparison**: Compare up to 3 products side-by-side with a floating dock.

### 💳 Checkout & Savings
- **Promo Codes**: Instant discounts using codes like `BUYHELPS10` or `FESTIVE500`.
- **Buyhelps Cash Wallet**: 1-click deduction of up to **₹1,250** available balance at checkout.
- **1-Click Address Selector**: Pick between Home, Work, or Family addresses instantly.
- **Luxury Gift Packaging**: Add custom gift wrap, ribbon seal, and a greeting card note (+₹99).

### 📦 Tracking, Support & Trust
- **Live BlueDart Tracking**: 5-step visual shipment milestones for order `#BUYHELPS-2026-84920`.
- **Printable GST Tax Invoice**: Download or print a clean A4 GST tax invoice with 1 click.
- **AI Support Assistant**: Bottom-right floating chat assistant for instant answers on orders, returns, and wallet queries.
- **Social Proof Notifications**: Real-time popups of verified purchases across Indian cities.
